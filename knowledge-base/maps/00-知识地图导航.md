# 知识地图导航

> `maps` 只表达跨主题关系、访问链路和分层拓扑，不承载规则与结论；规则以 [../solutions/00-正式正文导航.md](../solutions/00-正式正文导航.md) 为准。

## 地图规划

| 地图 | 表达什么 | 状态 | 开启条件 |
|---|---|---|---|
| 00-AI研究全景地图 | 强化学习、深度学习、Agent、协议四条线之间的分层关系：算法 → 模型 → Agent 框架 → 协议与工具链 → 评测。 | 未开启 | 第 01/03 章任一开启后，由该章的跨箱引用关系提炼 |
| 01-Agent工具链地图 | Agent 调用链：模型 → 推理/规划 → 工具调用 → MCP 客户端/服务器 → 外部系统，以及评测切入点。 | 未开启 | `02-agent` 与 `03-mcp` 各有 ≥1 个成熟箱 |
| 02-证据到正文追溯图 | 每个正文章节依赖哪些箱与证据块，用于判断证据衰减与复核优先级。 | 未开启 | 正文开启 ≥3 章 |

## 使用规则

- 地图页面只画关系与链路，不写「应该怎么做」；判断与规则回正文。
- 地图中的每个关系必须能沿链接回到某个箱或正文小节，无法追溯的关系不画。
