# 实现参考导航

> `references` 保存参数、接口、版本、配置等可直接查表的内容；若与正文冲突，以 [../solutions/00-正式正文导航.md](../solutions/00-正式正文导航.md) 为准。

## 参考页规划

| 参考 | 内容 | 状态 | 开启条件 |
|---|---|---|---|
| MCP版本演进参考 | MCP spec 各版本的发布时间、能力项增减、弃用与迁移要点（来源：specification 仓库 releases 与 changelog）。 | 未开启 | `03-mcp` 域「mcp-spec-evolution」箱积累 ≥2 个版本的 A 级证据 |
| 评测基准速查 | 各基准的任务形态、评分口径、污染风险与已知偏差一览表。 | 未开启 | `04-benchmarks` 域任一箱证据 ≥3 块 |
| 开源框架版本参考 | 推理/Agent 框架与 MCP SDK 的版本线、破坏性变更与最低依赖要求。 | 未开启 | `05-code-oss` 域出现 ≥2 个箱 |
| 论文与术语缩写表 | 领域内高频缩写（GRPO、DPO、PPRM、SoM 等）与本文库采用的中文译法。 | 未开启 | 正文任一章开启 |

## 使用规则

- 参考页只放事实表与速查，不写论证过程；论证回正文，证据回 `Sources`。
- 表格必须给出口径与复现命令（如 `grep`/`find`/API 端点），复现不了的数字不得入表。
