# 00-01 证据分级与引用口径

## 1. 定位与摘要

本文规定本库引用外部资料时的证据分级、预印本处理方式、版权边界和标准引用格式。所有正文与箱在登记、提炼、引用时以本文为准；采集落盘的字段级要求见 [../../../Sources/归箱规则.md](../../../Sources/归箱规则.md) §6。

## 2. 适用边界

适用：`Sources` 证据块的等级标注、`knowledge-base` 正文的引用写法、`outputs/weekly` 分析的建议采纳判断。

不适用：证据块的字段结构与查重口径（归箱规则管）、正文的章节组织（AGENTS.md 的正文模板管）。

## 3. 证据分级

| 等级 | 定义 | 典型来源 | 可支撑什么 |
|---|---|---|---|
| A | 一手原件 | 论文原文（含 arXiv 预印本）、协议/spec 原文、官方文档与官方发布公告 | 事实陈述与定量结论（预印本须加限定） |
| B | 深度二次材料 | 白皮书、综述、课程与教程、厂商工程博客的深度分析 | 方法背景与趋势判断，不单独支撑定量结论 |
| C | 转述 | 新闻报道、榜单、社区摘要 | 只作线索，**不得作为定量结论来源** |

判定顺序：能拿到原件就是 A；只有深度分析是 B；只有转述是 C。混合来源按最低可用等级登记，并在「可提炼要点」里标明各条依据。

## 4. 预印本与复现口径

- arXiv 预印本按 A 级一手来源登记，但「适用范围」必须以 `preprint` 开头注明未经同行评议。
- 引用预印本的定量结论时，写法为「（预印本，未复现）」；有本地复现或官方复现记录时改为「已复现，见 <证据块>」。
- 同一工作的多个版本以最新 vN 为准；v1→vN 结论发生变化的，在证据块「可提炼要点」写明差异，不重复开箱。
- 会议录用后（camera-ready 或 proceedings DOI），把证据块的适用范围更新为「已同行评议」，等级不变。

## 5. 版权与引用边界

- 正文层只写自己的提炼和不超过一段的短引，标注 `arXiv:<id>` / DOI 与章节号。
- 不把论文、规范的整篇或整节复制进 `knowledge-base`；PDF 原件只保存在 `Sources` 供个人研究，不对外分发。
- 代码片段按其许可证处理，注明仓库与 license；不搬运无许可证仓库的代码。
- 付费墙与登录墙内容只登记标题、DOI/URL 与公开摘要，不记录绕过方式。

## 6. 引用模板

正文引用证据块：

```markdown
……策略梯度项在长上下文下出现方差放大（见 <grpo-rlhf-source>#E2，A 级，preprint，未复现）。
```

引用原件但不入箱（临时查证）：

```markdown
……见 arXiv:2510.01234 §4.2（原件登记于 00-rl/.inbox/，合箱后移入 <箱名>）。
```

## 7. 风险与权衡

- 分级是判断不是事实：同一材料可能 A（一手）但结论未被复现——等级回答「来源是否一手」，复现状态回答「结论是否可信」，两者必须分开写。
- 把 C 级写进正文是最常见的失败路径：来源链一断，结论就悬空；宁可正文留缺口并在 `Sources` 记关闭条件。
- 为凑等级而降级一手来源（例如把官方 spec 记成 B）会让查重与引用口径失真；等级只看来源类型。
