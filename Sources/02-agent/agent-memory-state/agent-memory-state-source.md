## E1 · MemTrial：经验信用要归因于「经验改变了什么」

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.11732
- 本地原件：—
- 适用范围：preprint，未经同行评议；场景为 LLM 组合管理 Agent（PortBench、InvestorBench 等 4 个基准），结论限定在金融决策记忆，不直接外推到通用工具调用记忆。
- 证据等级：A
- 可提炼要点：
  1. 失败模式：按决策结果给记忆条目记信用时，收益主要反映当天市场整体涨跌，信用跟的是市场而不是经验——这类 Agent 常跑输 1/N 等权组合。
  2. MemTrial 的做法：同一决策在「有/无该经验」两种草稿下面对同一市场，差分消掉共同结果；用分数因子设计取 8 种检索组合，以 Banzhaf 值给经验记信用，再用分层贝叶斯跨日期/相似经验池化，只有在能预测未见日期后才采纳，否则回退到保守参考（如 1/N）。
  3. 量化：四基准上最好 15 个方法的半合成基准取最优；PortBench/InvestorBench 相对 1/N 最多亏 2.2%（对照最佳经验学习 Agent 亏 15–38%）；平均提升最佳经验学习 Agent 效用 21.2%，八款 LLM 上在 InvestorBench 全部胜过基线。
- 关闭条件：缺通用 Agent（非金融）记忆信用的验证；需评估 8 组合草稿的成本开销。

## E2 · Memento 3：自然语言规则簿作为可修正世界模型

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.11794
- 本地原件：—
- 适用范围：preprint，未经同行评议；底座 LLM 冻结、只改外部记忆的持续学习；评测为 ARC-AGI-3 公开 25 关与 Atari Pong 案例。
- 证据等级：A
- 可提炼要点：
  1. 结构：Agent 维护自然语言规则簿作为持久语义记忆（记录可修正的环境动力学假设，未知处留白），再把规则簿编译为可执行代码做预测与规划；观察→反思→修订→编译→验证的闭环用预测误差同时改进规则簿与代码。
  2. 接受准则：更新后的代码只有在 LLM 判断忠实于规则簿、且 cell-exact replay 复现观测转移时才被接受——这是把「自我改进」关进可验证闸门的做法。
  3. 结果：单模型 Agent 通关 ARC-AGI-3 全部 25 个公开游戏，RHAE 均值 100.0、动作数为人类的 44%；Pop 扩展并行维护多个世界模型共享交互证据；Atari Pong 案例中学到的反馈控制器三次开局均 21:0 获胜且不再调用 LLM。
- 关闭条件：需读正文确认规则簿规模上限与跨任务迁移边界；「RSI」表述应按 preprint 谨慎引用，缺独立复现。

## E3 · Ontology Tower：窄而深的领域知识比检索式日志更有效

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.11768
- 本地原件：—
- 适用范围：preprint，未经同行评议；单一工业设备系统（低湿度空气处理试验台）的预注册评测，9 项任务回放、4 款开源模型（9B~约 750B）；不覆盖多站点通用本体。
- 证据等级：A
- 可提炼要点：
  1. 结构主张：既有的建筑本体「点多种类少」，设备系统需要的是「实体少、每个实体知识深」的窄而深本体——知识通过物理关系推导量与运行日志经验两条路径加深。
  2. 关键负结果：运行经验写进本体塔或放进 prompt 时 Agent 会用，**放在日志里靠搜索工具取用时几乎不用**——对「记忆该放哪一层」是直接可操作的证据。
  3. 量化：知识使 Agent 避开最可能误判的比例提高约 20 个百分点，9B 模型任务总分追平最大模型；经不变式安全层的实机 14 次运行中 12 次把被控变量带入目标区间。
- 关闭条件：单一试验台、任务数 9，缺跨设备泛化证据；需与向量检索 RAG 基线同口径对比。
