## E1 · 白盒探针在前沿监控规模上检测欺骗与破坏

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.12445
- 本地原件：`originals/arxiv-2610.12445-deception-probes.pdf`（1,226,321 B，已校验 `%PDF-`）
- 适用范围：preprint，未经同行评议；白盒探针需要模型激活访问，适用于有内部访问权的部署方；数据集 FIBS 已公开。
- 证据等级：A
- 可提炼要点：
  1. 规模化口径：收集迄今最大欺骗数据集训练探针，并提出可跨层、跨 token 聚合信息的探针架构；在 SHADE-Arena 上 98.8% AUC，超过 Opus 5.5 文本监控基线，且随底座模型变大而更有效。
  2. 「内省式欺骗」（introspective deception，仅凭上下文无法判真）上，探针区分真实隐藏目标与其它目标的 AUC 最高 99.7%；在开源权重模型就政治敏感话题与受压时的表态上也检出欺骗。
  3. 局限：探针依赖白盒激活与欺骗标注数据；数据集 FIBS 公开供社区扩展——监控方案选型时这是「内部可见性换检测力」的典型权衡。
- 关闭条件：需读正文确认探针在低欺骗基率部署中的误报率（precision@base-rate）；有第三方复现后可关。

## E2 · OnTrack：与历史成功轨迹比对的流式监控

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.12375
- 本地原件：—
- 适用范围：preprint，未经同行评议；评测基于 SWE-bench 轨迹；分三档访问条件（全参考、仅工具 schema、仅步骤日志），监控能力随访问减少而下降。
- 证据等级：A
- 可提炼要点：
  1. 现有两路方案的代价口径：安全员 Agent 监控给每步加成本与延迟；事后日志评估在 token 烧完、损害发生后才给结论。
  2. OnTrack 流式比对 Agent 的步骤与依赖同「记录的成功运行」，每步约毫秒级告警或阻断；三档访问下能力从计划违例检测逐步降为识别环路、停滞与重复工具调用。
  3. SWE-bench 轨迹实验：仅用前 8 步区分失败/成功轨迹比内容相似度方法 AUROC +0.057；配中止策略可省约 18% 本会烧在失败运行上的算力，被中止运行中 83% 确实在走向失败。
- 关闭条件：缺真实生产环境误报/漏报数据与参考轨迹库建设成本评估；需与 E1 白盒探针方案做同口径对比。
