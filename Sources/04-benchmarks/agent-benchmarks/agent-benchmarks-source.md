## E1 · AgenticBBO-Bench：统一预算协议下的跨域 Agent 黑盒优化

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.12183
- 本地原件：—
- 适用范围：preprint，未经同行评议；五类任务（合成函数、超参优化、数据库调优、芯片设计、分子设计）的有限预算协议；代码开源（github.com/lamda-bbo/agentic-bbo）。
- 证据等级：A
- 可提炼要点：
  1. 立项口径：既有 agentic BBO 研究任务域与系统配置各不相同，结果不可比、单项设计选择的影响无法隔离——基准的贡献首先是**统一有限预算评测协议**。
  2. 五域结果：agentic BBO 家族平均分全部高于直接 LLM 方法，四域胜过最佳数值优化器；数值工具并非总能提升性能，任务语义普遍有用而更具体的先验知识更不可靠，数值优化器能吸收 Agent 搜索轨迹的收益。
  3. 五任务前沿挑战中评估 7 款 LLM（Codex harness），GPT-6 Astra 与 DeepSeek-V4.1-Flash 位于性能-成本 Pareto 前沿。
- 关闭条件：需跟踪基准使用情况与 leaderboard 污染风险；榜单数据以代码仓库为准，登记后可关。

## E2 · GNA：工具层固定为 MCP server 的部署前评测框架

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.09112
- 本地原件：—
- 适用范围：preprint，未经同行评议；地理空间/环境任务域，16 个工具的 MCP server、103 任务（93 主套 + 10 扩展）、确定性打分器、9 款 LLM × 3 温度种子；可换工具执行器复用框架。
- 证据等级：A
- 可提炼要点：
  1. 方法学要点：把工具层固定成同一个 MCP server，使**被测 Agent 成为唯一变量**——这是工具使用评测控制变量的可复用范式。
  2. 结果：Claude Sonnet 4 能力最高（103 任务 61.7%±0.7），DeepSeek V3.2 57.9%，其余均不超过 53%；成本-准确率 Pareto 前沿大多为开源权重（DeepSeek V3.2 以 1/11.3 标价成本达 Claude 93% 能力）。
  3. 评分协议敏感性：严格全检打分下最好模型比通用 GIS 基准报告的 85–97% 低 24–36 分，而逐检部分得分（86–90%）相当——**差距主要来自评分严格度而非任务难度**，跨基准比较必须注明打分口径。
- 关闭条件：需读正文确认任务泄漏与 API 漂移控制；框架与基准已公开，复现后可关。

## E3 · AAArena：固定权重、改代码策略的对局制学习评测

- 获取日期：2026-10-09
- 来源 URL：https://arxiv.org/abs/2610.12341
- 本地原件：—
- 适用范围：preprint，未经同行评议；12 个真实对抗游戏、1,920 个归档人类程序，按真实赛事协议评测；模型权重固定，Agent 通过改写游戏策略与支撑软件学习。
- 证据等级：A
- 可提炼要点：
  1. 形式化 Adversarial Heuristic Learning（AHL）：AI Agent 作为学习引擎改进可执行策略，权重不动——把「学习」定位到代码/策略层而非参数层。
  2. 结果：Opus5.5 + Claude Code 拿 6 金；**没有任何评测配置登顶其余 6 个人类阶梯**；规则越复杂表现越弱——长程策略与规则理解仍是瓶颈。
  3. 消融：对手选择与密集反馈支撑策略改进；Agent 既能从自己对局的 on-policy 回放学习，也能从他人对局的 off-policy 回放学习。
- 关闭条件：需跟踪人类阶梯的更新与更多模型/ harness 组合；单篇 preprint，缺第三方复现。
